Problems first

Attempt these before you open a book or a video. Write the argument in the work box and the conclusion in the answer box. Check counts the problem only when both pass, and it does not open the solution. The solution stays locked for twenty minutes after you start the timer.

Attack 1

How many ways can you choose 2 elements from a set of \(n\)? Derive the formula, do not quote it.

Timer not started. Twenty minutes of real work before a solution.

There are \(n(n-1)\) ordered pairs of distinct elements, and each unordered pair was counted twice, so \(\binom{n}{2}=n(n-1)/2\).

Attack 2

Prove the handshake lemma: the sum of degrees in a graph is twice the number of edges.

Timer not started. Twenty minutes of real work before a solution.

Count the set of pairs \((v,e)\) with \(v\) incident to \(e\) in two ways. Summing degrees counts each edge twice, once at each end.

Attack 3

Use inclusion–exclusion to count the integers from 1 to 100 that are divisible by 2 or 3 or 5.

Timer not started. Twenty minutes of real work before a solution.

\(\lfloor 100/2\rfloor+\lfloor 100/3\rfloor+\lfloor 100/5\rfloor-\lfloor 100/6\rfloor-\lfloor 100/10\rfloor-\lfloor 100/15\rfloor+\lfloor 100/30\rfloor=50+33+20-16-10-6+3=74\).

What this actually is

Combinatorics on this page means counting, bijections, generating functions, and the first graph-theoretic facts you need in order to not be helpless on an olympiad or a Putnam A1. The binomial theorem, inclusion–exclusion, pigeonhole, and recurrence relations are the whole elementary theory. Ordinary generating functions turn linear recurrences into algebra. A graph is a set of vertices and edges; trees, bipartite graphs, and the handshake lemma are the part you must be able to prove in a paragraph.

Lehman, Leighton, and Meyer’s Mathematics for Computer Science is free and contains a serious counting and graph section. It is the working text. Wilf’s generatingfunctionology is the right specialized book; the Penn URL that used to host it did not return a stable copy in this check, so it is not linked. Use the generating-function chapters of the MIT notes instead. AIME and Putnam counting problems are the ceiling.

A counting argument that does not say what is being counted, and in what order, is a guess with binomial coefficients glued on.

Core results

Statements only. Write the argument before you reveal it. A revealed proof you did not attempt is a paragraph you will not be able to rebuild at 2am.

  1. Binomial theorem. \((x+y)^n=\sum_{k=0}^n\binom{n}{k}x^{n-k}y^k\). Pascal’s recurrence \(\binom{n}{k}=\binom{n-1}{k}+\binom{n-1}{k-1}\) has a bijective proof.

    The binomial theorem is the distributive law: each term picks \(x\) or \(y\) from each factor. Pascal: a \(k\)-subset of an \(n\)-set either contains a distinguished element or it does not.

  2. Inclusion–exclusion and pigeonhole. The size of a union is the alternating sum of the sizes of intersections. If more than \(kn\) pigeons sit in \(n\) holes, some hole has at least \(k+1\) pigeons.

    Inclusion–exclusion is induction on the number of sets, or an indicator-function identity: \(\prod(1-1_{A_i})\) expands to the alternating sum. Pigeonhole is the contrapositive of “\(k\) per hole gives at most \(kn\).”

  3. Recurrences and generating functions. The ordinary generating function of a sequence turns a linear recurrence into a rational function. The Fibonacci generating function is \(x/(1-x-x^2)\). Partial fractions extract coefficients.

    Multiply the recurrence by \(x^n\) and sum. The initial conditions fix the numerator. Partial fractions and the geometric series give the Binet-style closed form if you want it; the generating function is already the answer for many problems.

  4. Graphs. Handshake lemma. A tree on \(n\) vertices has \(n-1\) edges and is connected and acyclic; any two of those properties imply the third, among the usual list. A graph is bipartite if and only if it has no odd cycle.

    A tree has a leaf; delete it and induct to get \(n-1\) edges. Bipartite: color by distance from a vertex on each component; an odd cycle makes the color inconsistent. Conversely an odd cycle cannot be 2-colored.

  5. Double counting. If you count a set of pairs in two ways, you get an identity. This is the source of the handshake lemma, of \(\sum k\binom{n}{k}=n2^{n-1}\), and of most olympiad counting proofs that look like magic.

    The identity \(\sum k\binom{n}{k}=n2^{n-1}\) counts pairs \((x,S)\) with \(x\in S\subseteq\{1,\ldots,n\}\): choose the distinguished element first, or choose the set and then the element.

The ladder

Four rungs, in order. Do not skip a rung because the next one looks more serious.

Hardest questions

Names and links. The problem text stays on the source site. Copyrighted contest problems are not copied here. What follows is where they are and why they hurt.

  1. AIME counting, problems 10–15
    Overcounting is the entire difficulty. The arithmetic is nothing.
  2. Po-Shen Loh, combinatorics at the top rating
    Sorted, so you cannot hide in algebra.
  3. Borisov, combinatorics
    Putnam counting problems are proofs, not three-digit answers.
  4. Handshake lemma and the tree theorem, blank page
    If these are not instant, the later problems will be folklore you cannot use.
  5. Fibonacci generating function, derived
    One derivation teaches the method. A memorized Binet formula does not.

Mastery gate

Pass: handshake lemma, binomial theorem, and inclusion–exclusion for three sets, from memory, plus five AIME counting problems numbered 8 or higher and two Putnam combinatorics problems with full proofs. Fail if a count does not name the set being counted.

Diagrams

Escalating sets

Five sets. Finish a set before you touch the next. Full sentences, not a circled answer.

Set 1. Counts

  1. Derive \(\binom{n}{2}\).
  2. Pascal’s identity, bijectively.
  3. Binomial theorem for \(n=3\), expanded by hand, then the general proof.
  4. How many subsets does an \(n\)-set have? Two proofs.
  5. \(\sum k\binom{n}{k}=n2^{n-1}\), by double counting.

Set 2. Inclusion and pigeons

  1. Integers from 1 to 100 divisible by 2, 3, or 5.
  2. Derangements of 3 items, by inclusion–exclusion.
  3. Pigeonhole: among 5 integers, two have the same remainder mod 4.
  4. Five points in a square of side 1; two are at most \(\sqrt{2}/2\) apart. Prove it.
  5. State inclusion–exclusion for three sets from memory.

Set 3. Recurrences

  1. Fibonacci recurrence, first ten terms, and the generating function.
  2. Number of binary strings of length \(n\) with no two consecutive 1s. Find the recurrence.
  3. Solve \(a_n=3a_{n-1}\), \(a_0=2\).
  4. A linear recurrence of order 2, characteristic polynomial, one example.
  5. Partial fractions of \(x/(1-x-x^2)\), as far as you are willing to go.

Set 4. Graphs

  1. Handshake lemma.
  2. A tree has \(n-1\) edges.
  3. Prove bipartite iff no odd cycle.
  4. Draw a connected graph with exactly one cycle and count its edges.
  5. Euler’s formula \(V-E+F=2\) for a connected plane graph, proved by induction or clearly cited as not yet proved.

Set 5. Ceiling

  1. Five AIME counting problems.
  2. Two Putnam combinatorics proofs.
  3. Generating function of the no-consecutive-1s strings.
  4. Oral handshake lemma.
  5. One double-counting identity you invent and then prove.
